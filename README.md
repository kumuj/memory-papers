# Agent Memory 已读论文资料库

## 首次发布

1. 将 `index.html`、`paper_app.js`、`paper_data.js` 和本说明上传到仓库根目录，提交至 `main` 分支。
2. 打开仓库 **Settings → Pages**。
3. Source 选择 **Deploy from a branch**。
4. Branch 选择 **main**，目录选择 **/ (root)**，点击 **Save**。
5. 等待 Pages 发布完成。固定网址：https://kumuj.github.io/memory-papers/

## 后续更新

更新并提交 `paper_data.js` 后，等待 GitHub Pages 部署完成。所有访问者使用原网址即可看到新版；打开中的页面每 10 秒检查数据，并保留筛选条件。GitHub 部署和缓存传播可能需要几分钟。

本网页只提供查看和筛选。持有网址的人不能修改资料，除非另行获得仓库写入权限。

发布内容为公开论文的题名、框架、数据集、设置与来源链接，不含论文全文和原始阅读文档。
